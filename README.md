# Smart-Irrigation-Fault-Detection-System 

The Smart Irrigation Fault Detection System uses Machine Learning techniques to monitor irrigation systems and identify abnormal conditions. Sensor data including soil moisture, temperature, humidity, light intensity, water flow rate, and pump pressure are collected and processed. The data is scaled and used to train a Support Vector Machine (SVM) classifier. The trained model predicts whether the irrigation system is operating normally or experiencing a fault.


# Objective :- 

1. To develop an intelligent irrigation monitoring system using Machine Learning.
2. To detect normal and faulty irrigation conditions automatically.
3. To analyze sensor data such as soil moisture, temperature, humidity, light intensity, water flow rate, and pump pressure.
4. To improve irrigation efficiency and reduce water wastage.
5. To provide timely fault detection for better agricultural productivity.


# Key Features :- 

1. Real-time irrigation condition monitoring.
2. Automated fault detection using Machine Learning.
3. Analysis of multiple environmental and irrigation parameters.
4. High classification accuracy using SVM.
5. Early warning system for irrigation failures.
6. Scalable and adaptable for different agricultural environments.
7. Supports smart farming and precision agriculture.


# Result :- 

1. Successfully trained an SVM classifier on irrigation sensor data.
2. Accurately classified irrigation conditions as Normal or Faulty.
3. Improved fault detection capability compared to manual monitoring.
4. Demonstrated effective use of sensor data for decision-making.
5. Reduced response time in identifying irrigation system issues.


# Conclusion :- 

The Smart Irrigation Fault Detection System effectively utilizes Support Vector Machine (SVM) algorithms to identify irrigation faults based on sensor readings. The system enhances agricultural efficiency by enabling automated monitoring and early fault detection. It helps conserve water, reduces maintenance efforts, and supports sustainable farming practices. The project demonstrates the practical application of Machine Learning in modern agriculture and smart irrigation management.
